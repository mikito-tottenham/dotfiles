親が `.context/<task>/NN-grill-rN-response.md` に書く。Grill 結果と整合レビューの指摘を全件載せ、1 件ずつ採否を決める。


## 裁定の既定ルール

| 指摘の種類 | 既定 |
|---|---|
| 事実誤認、技術的な誤り、計算の誤り | 採用。出典を確かめてから直す |
| 送付済み文書・後続合意との不整合 | 採用。後続の合意を優先して揃える |
| 相手に伝えた条件・提供範囲・成果物を超える約束 | 保留。伝えた範囲を既定として残し、ユーザーに確認する |
| 文書側では決められない事業判断 | 保留。「ユーザー裁定が必要な論点」に載せる |
| 構成・順序の改善 | 文書の目的に効くなら採用。効かないなら理由を書いて却下 |
| 好みの範囲の表現 | 却下してよい。理由を 1 行書く |

- 却下や保留にも理由を必ず書く。理由の無い却下は次ラウンドで同じ指摘が戻る原因になる
- 同じ指摘が別ラウンドで再び出た場合は、前ラウンドの ID を「出所」に併記する
