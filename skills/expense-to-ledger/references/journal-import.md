# 仕訳データの取り込み仕様

列の定義は会計システムの公式ヘルプ、または画面からダウンロードできるサンプル・テンプレートを正本にする。この文書や記憶から列名を組み立てない。repo に過去の取り込み実績ファイルがあれば、そのヘッダーを流用する。

## マネーフォワード クラウド会計（仕訳帳インポート）

- 列: 公式ヘルプ「『仕訳帳』をインポートする」の仕様（取引 No から始まる列構成）に合わせる
- 文字コード: UTF-8 **BOM 付き**。BOM が無いと文字化けする
- 取引日: `yyyy/MM/dd`
- 税区分: 会計システム上の正式名称を使う（例: `課税仕入 10%`、`対象外`）。別表記は変換する。正式名称は `mfc_ca_getTaxes` で確認できる
- 税額列: 空欄にして自動計算に任せる（プロファイルに別の定めがあればそれに従う）
- 勘定科目・補助科目・部門: 事業所側に存在する名称と一致させる。`mfc_ca_getAccounts` / `mfc_ca_getSubAccounts` / `mfc_ca_getDepartments` で照合し、存在しない科目は要確認に載せる
- 出力前に借方合計と貸方合計の一致を確認する

## freee

- 取り込み方法（CSV インポート、API の取引作成、経費申請）を最初に決め、プロファイルの `ledger_system` に書く
- CSV の場合は freee の画面からダウンロードしたテンプレートの列に合わせる
- API の場合は勘定科目 ID、税区分コード、口座 ID（決済済みの場合）を事前に取得して照合する

## 管理会計など会計システムからの取り込み

会計システムから出力した試算表などを社内の実績ファイルへ変換する場合も、同じ検証ゲートを使う。

- 既定は検証のみ。書き込みは明示フラグを付けたときだけ
- 部門マッピングに無い部門、マスタに無い勘定科目を NG とする
- 部門未付与の金額を検出し、付与率を出す
- 合計列との突合を許容差つきで行う
- NG があれば終了コードを非 0 にし、出力ファイルを書かない
