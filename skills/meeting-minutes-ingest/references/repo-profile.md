# Repo Profile and Default Formats

保存先 repo の議事録規約を拾うためのチェックリストと、規約が無い repo で使う既定書式。repo の文書と食い違う場合は、常に repo の文書を正とする。

## 読む順番

1. repo の `AGENTS.md`（`CLAUDE.md` が import している場合も含む）で「議事録」「文字起こし」「meetings」「mtg」を検索する
2. 議事録フォルダの索引: `docs/mtg/README.md`、`docs/meetings/README.md`、`meetings/README.md`、`<番号>_議事録*/README.md` など
3. 議事録の保存方針を決めた ADR（`docs/adr/` を「議事録」「meeting」で検索）
4. repo ローカルの skill（`.claude/skills/`、`.agents/skills/`）のうち、議事録の取り込み・同期・レビューを扱うもの
5. テンプレート（`templates/`、`<番号>_テンプレート/` など）と、規約が参照実装として挙げている既存の議事録
6. 文字起こしの補正辞書（`transcript-corrections.md` など）と、その追記ルール

見つからない項目は推測で埋めず、`01-profile.md` に「repo に規定なし」と書く。

## 拾う項目

| 項目 | 見るポイント |
|---|---|
| 保存先 | 会議体・相手先・社内外などでサブフォルダを分けるか。分類の判定基準。直下に置かれた古いファイルを踏襲しないか |
| 命名 | 例: `YYYYMMDD_会議名_議事録.md`、`<件名slug>-YYYY-MM-DD.md`、`mtg-YYYY-MM-DD-<slug>.md`。年を含む完全な日付が必須か |
| 会議名 | 録音ツールが付けた会議名ラベルを正とするか |
| Front Matter | 必須キー（例: `title` / `date` / `participants` / `status` / `source` / `confidentiality` / `recorder` / `note`） |
| 本文の書式 | テンプレートの有無、機密レベル表示、表記上の注意、要確認事項表、アクション表、次回アジェンダ、更新履歴 |
| 文字起こし全文 | 議事録と並べてコミットするか、git 管理外（`.context/` など）だけに置くか。全文の書式（例: `### 話者名 HH:MM:SS`） |
| 機密の境界 | 本文に載せない情報（実名、金額、関係性の評価、個人連絡先、率直な本音）と、その情報の置き場 |
| 補正辞書 | path、適用のタイミング、追記してよい情報と別ファイルへ分ける情報 |
| 索引 | 1 行追記する場所と既存行の書式 |
| タスク台帳 | 議事録作成のターンで台帳を更新してよいか、反映案だけに留めるか、別のタスクリストで管理するか |
| 正本と複製 | 別 repo に同じ議事録を置く規定があるか。どちらが正本か |
| 文体 | 敬語・謙譲語の使い方、常体／敬体、相手の行為の書き方など、repo 固有の文体規約 |
| 数値のラベル | 口頭由来の数値に付けるラベル（例: `要確認`）の規約 |
| 検証 | リンクチェックや Front Matter 検査の script |

## 観測済みの規約パターン

2026-10 時点で複数の repo に見られた型。どの型かを判断する手がかりとして使い、そのまま採用しない。

- **2 ファイル型**: 会議ごとに構造化した議事録と、原文ままの文字起こし全文を同じフォルダに置く。タスクが多い会議では、ネクストアクションのレポートを別ファイルで足す
- **2 層型**: 逐語の文字起こしは機密として git 管理外に置き、機密を除いた議事録だけをコミットする。議事録の Front Matter から raw の出典を参照する
- **単一ファイル型**: `meetings/` に会議ごとの議事録を 1 本置く。Drive 上の文書から取り込む skill を repo が持つことがある
- **分類サブフォルダ型**: 参加者や相手先の基準でサブフォルダを分け、索引 README に判定基準と現在のファイル一覧を持つ。補正辞書を索引と同じ階層に置く

## 既定書式（repo に規約が無い場合）

`soundcore-minutes` の `references/output-formats.md` の Standard Minutes を基本にし、次を足す。

```markdown
---
title: <会議名>
date: <YYYY-MM-DD>
participants: [<参加者 or 未確認>]
source: <出典>
status: draft
---

# <会議名>

> 表記上の注意: <補正した固有名詞と、表記ママで残した箇所>

## 要約
## 決定事項
## アクションアイテム
| 担当 | 期限 | 内容 | 根拠（発言時刻） |
| --- | --- | --- | --- |
## 論点・議論メモ
## 要確認事項
| 箇所 | 内容 | 確認先 |
| --- | --- | --- |
```

## 最終報告の型

```markdown
- 出典: <録音タイトルと日時 / ファイル名>
- 保存先: <path>（索引: <path> に 1 行追記）
- 話者: <ラベル → 人物>。確度の低い対応: <なし / 内容>
- 決定事項: <箇条書き>
- アクション: <担当 / 期限 / 内容>
- 要確認: <箇条書き>
- 辞書: <追記した項目 / 追記案>
- 台帳: <反映した / 反映案のみ / 対象外>
- コミット: <hash / 未コミットの理由>
```
